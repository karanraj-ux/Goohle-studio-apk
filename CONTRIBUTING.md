# Contributing Guidelines

Thank you for your interest in contributing to Shield & Forward! We welcome community contributions.

## How to Contribute
1. Fork the repository.
2. Create a new branch for your feature or bugfix (`git checkout -b feature/your-feature-name`).
3. Commit your changes with descriptive messages.
4. Push to your branch and open a Pull Request.

## Code Style
- We follow standard Kotlin coding conventions.
- UI elements should be written using Jetpack Compose and adhere to Material 3 guidelines.
- Database changes must include proper Room migration plans.

## Bug Reports
Please use the GitHub Issues tab to report bugs. Include:
- Device model and Android version.
- Steps to reproduce the issue.
- Any relevant logs (ensure no personal data is included).
